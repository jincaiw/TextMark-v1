TextMark portable / 便携版
==========================

Run TextMark.exe directly. No installation or administrator rights are required.
The Microsoft Edge WebView2 Runtime is required on Windows 10/11.
Portable builds do not install file associations or Explorer Preview Handler entries.

直接运行 TextMark.exe，无需安装或管理员权限。
Windows 10/11 需要 Microsoft Edge WebView2 Runtime。
便携版不会写入文件关联，也不会注册资源管理器预览处理程序。
