### 环境坑（第三轮新增）

- **`ps` 在本沙箱被拒**（`operation not permitted`），`ps -p X || echo gone` 会因 `ps` 自身失败而误报
  「进程已退出」；判断进程存活要用 `pgrep -f`。
- **`osascript -e 'tell application "X" to quit'` 返回 -10004 权限违例**，应用不会退出；
  用 `kill <pid>` 才有效。退出前 `open -n` 不会启动新实例（同名 bundle 被去重），
  必须先确认旧进程真的没了再 `open`。
- 对 47MB debug 二进制做 `cmp` 会被沙箱 SIGKILL（exit 137），改用 `shasum -a 256` 分别算后比对。
- CDP 直连取巧法：`agent-browser get cdp-url` 拿 ws 地址 → `fetch /json/list` 找 page target →
  用 **Node 22 内置 WebSocket**（无需装 `ws` 包）发 `Emulation.setEmulatedMedia {media:'print'}`
  再 `Runtime.evaluate` 读 computed style。这比在 CSSOM 里翻 `cssText`（含换行、会打断 CLI 传输）干净得多。
