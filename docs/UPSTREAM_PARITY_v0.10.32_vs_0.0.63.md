# TextMark v0.10.32 工作树与 Markdown Preview v0.0.63 对照

对照基准：Markdown Preview 官方 [v0.0.63 Release](https://github.com/pluk-inc/markdown-preview/releases/tag/v0.0.63)，于 2026-09-28 发布。TextMark 当前正式版为 v0.10.32；本文记录其后的未发布工作树改动，不代表 v0.10.32 安装包已包含这些改动。

2026-09-29 实际查看本机两款应用及同一 `MARKDOWN_RENDERING_TEST.md`。将两边窗口设为半屏、打开目录侧栏、编辑模式和相同文档章节，并将上游主题临时切到深色做截图对照；检查后已恢复上游“自动”主题。截图确认上游目录导航保留光标，而 TextMark 原先会把光标移动到标题，导致 Markdown 标记暴露并破坏所见即所得阅读状态。本轮将编辑模式目录/标题导航改成纯滚动，不更改选择或焦点；增加 E2E 光标状态回归。界面细节仍存在两端原生窗口工具栏和格式工具栏实现差异，本轮聚焦对齐交互与内容行为，没有声称逐像素相同。

## 功能差异与处理

| v0.0.63 变化 | TextMark v0.10.32 原状 | 处理状态 |
| --- | --- | --- |
| 编辑模式任务复选框；Enter 延续待办、空任务退出列表 | 编辑器已有交互任务框、Enter 延续和退出行为 | 已有；编辑器和 E2E 回归覆盖 |
| 严格软换行设置同时影响阅读预览与 Quick Look | 已有设置、渲染器和导出贯通；独立 Mermaid 预览不使用 Markdown 段落换行 | 已有；完整桌面重启验证记录见验收报告 |
| 更新后显示 What's New，可从 Help 重开 | 无更新摘要窗口或菜单入口 | 本轮新增双语窗口、Help 菜单项和主窗口版本升级提示 |
| 阅读模式任务框和表格保持只读；编辑模式提供表格编辑 | 预览中任务框可改文档，表格可双击修改或用右键菜单改行列；导出的 HTML 任务框也可点击 | 本轮将预览及导出 HTML 中的任务框设为只读，阅读预览表格不可编辑；表格仍可选择、复制，编辑模式继续以所见即所得表格预览和 Markdown 源编辑为主 |
| 中文输入法组合输入期间标题标记保持稳定 | 标题分隔符根据光标位置隐藏/显示，未考虑 IME 组合状态 | 本轮组合输入期间持续显示标题标记，避免行宽和标题显示闪动 |
| 编辑模式文字大小立即生效 | TextMark 已将字号偏好应用到编辑器主题 | 已有；本轮未发现代码差距 |
| 窄工具栏下 Back/Forward 保持可见，文稿搜索框垂直居中 | 先前的顶栏和半屏 E2E 已覆盖窄窗口溢出收纳与搜索可达性 | 代码回归已有；在当前同宽窗口 AX/UI 检查中入口可达，无新增错位缺陷 |
| 搜索结果路径避免重复文件名，路径查询时单行显示完整层级并中部省略；悬停可查完整路径 | 原先始终显示相对路径且只在末尾截断 | 已实现：普通文件名搜索只显示父路径，包含斜杠的路径搜索保留首级目录和文件名、将中间层级省略，悬停显示绝对路径；组件测试覆盖。窄窗口折叠和结果布局由已有响应式测试覆盖 |
| 文档加载复用 reader、减少字体加载，并在符合条件时显示缓存预览 | TextMark 采用异步 Markdown Worker、延迟加载可选渲染器，并恢复编辑/滚动会话；没有与上游内部架构一一对应 | 机制不同，但没有发现可见的功能缺失或阻塞主线程缺陷；本轮没有宣称冷/热启动耗时相同，作为后续性能观察项，不作为发布阻断 |

## 本轮回归

- 前端：55 个测试文件、506 项通过；定向编辑器/预览/渲染/搜索/更新窗口测试 86 项通过。
- 发布构建：TypeScript、ESLint、Prettier、Vite 生产构建、bundle 预算通过（main+worker 312 KiB gzip、native preview 71 KiB gzip）。
- 导出：完整 HTML/PNG/PDF 回归通过，结果包含 6 个标题、2 张表格、2 个只读任务项、数学公式和 Mermaid 图；PNG 尺寸及 HTML 安全检查通过。
- 原生：Rust 27 项测试、Clippy 全目标检查、rustfmt 检查通过；macOS E2E shell 全套通过，25 项。
- 这些测试验证本地工作树；本轮尚未提交、尚未发布，也不代表已发布 v0.10.32 包变化。

## 2026-09-29 收尾结果

- 桌面同状态截图/AX 检查：两边使用同一文件、编辑模式、目录侧栏和半屏窗口；对照标题导航、代码/引用/HTML、工具栏入口。发现并修复目录导航抢占编辑光标的问题。上游外观恢复为“自动”。
- 测试：前端 506 项通过；macOS Shell E2E 26 项通过（包含大纲导航保留光标）；lint、格式检查、TypeScript/Vite build、Rust 27 项及 Clippy、导出回归与包体门禁通过。
- 性能差异：上游有 reader/snapshot 复用优化，TextMark 由 Worker 异步渲染并延迟加载可选模块；未测冷/热启动基准，不能声称耗时完全相同，但未发现功能或稳定性阻断。
- 发布要求：Windows/Linux 无真机，不执行真机测试；GitHub 托管 CI 按现行发布矩阵构建并烟测。macOS 使用 ad-hoc 签名，可在“系统设置 → 隐私与安全性”允许运行；不要求 Developer ID、公证和 Gatekeeper 验收。
