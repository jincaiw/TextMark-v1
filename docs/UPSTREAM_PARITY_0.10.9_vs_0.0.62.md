# TextMark v0.10.9 与 Markdown Preview v0.0.62 桌面对标

核对日期：2026-09-25。TextMark v0.10.9 以正式发布 tag `v0.10.8`（`a7c7856`）为基线；上游 Markdown Preview 最新发布为 `v0.0.62`（`62274b1`）。当前实现位于 `codex/release-v0.10.9`，没有回退到旧的 v0.9.7 分支。

## 比较范围

上游 0.0.62 的新增重点为项目文稿文件名搜索、紧凑前进/后退控件、阅读模式滚轮/横向内容滚动修复和 Mermaid 虚线箭头修复；0.0.61 已包含阅读及编辑代码卡片和浮动格式工具。TextMark 0.10.8 已具备工具栏自定义及溢出、查找覆盖层、编辑格式控件、滚动/焦点恢复、多文档标签和跨平台菜单等功能。本次在这一正式基线上补足 0.0.62 的桌面交互差异，保留 TextMark 的多文档及跨平台能力。

## 桌面 UI 与交互逐项比较

| 区域 | 上游 Markdown Preview 0.0.62 | TextMark v0.10.9 | 对齐情况 |
| --- | --- | --- | --- |
| 窗口和标题 | AppKit 原生标题栏、工具栏和标签；标题在原生窗口层级 | Tauri 原生窗口；窗口标题和侧栏承载文稿名，工具栏不重复显示标题 | 信息层级一致；系统控件外观按平台呈现 |
| 主工具栏 | 原生紧凑控件，可自定义工具项 | 沿用 v0.10.8 的可定制、可溢出工具栏；前进/后退为 26×26px 按钮、15px 图标 | 桌面占位已收紧；AppKit 与 Tauri 绘制不能逐像素相同 |
| 编辑格式工具 | 新系统使用紧凑浮动控件，旧系统使用附件栏 | v0.10.8 已有浮动格式覆盖层和窄窗回退布局 | 本次保留正式版实现，不重复覆盖 |
| 阅读代码块 | 圆角卡片、语言标签、复制与换行操作 | 每段围栏转换为卡片；固定语言、复制与换行按钮，状态按卡片独立 | 已实现；组件测试检查语言标题及换行切换 |
| 编辑代码块 | BlockWrapper 将围栏包含在独立卡片/滚动边界内，操作栏保持代码上下文 | CodeMirror BlockWrapper 卡片；语言编辑、复制正文、独立换行与卡片横向滚动 | 已实现；代码围栏源文本仍由 CodeMirror 编辑，操作不改写 Markdown |
| 项目文稿搜索 | ⇧⌘O；模糊文件名匹配；回车当前标签、⌘回车新标签、⌥回车新窗口；工具栏可选 | 文件菜单、快捷键及可定制工具栏均有入口；默认按文件名搜索，查询含 `/` 时改为相对路径搜索；同样提供三种打开操作 | 已实现；组件测试覆盖文件名筛选、路径搜索、高亮及三种打开动作 |
| 查找/编辑 | 编辑器搜索、格式、位置恢复 | 继承 v0.10.8 的编辑搜索、替换、焦点和位置恢复 | 保留正式版能力；不从旧分支回退 |
| 阅读滚动和图表 | 0.0.62 修复模式转换后滚动手势，并修正 Mermaid dotted block 箭头 | 预览区使用原生 `overflow:auto`；切换模式按阅读位置交接；依赖 Mermaid 11.16.1 | 源码及依赖版本已核对；本轮原生滚轮和 dotted 图仍需桌面运行截图复验 |
| 平台差异 | macOS 原生 AppKit | macOS、Windows、Linux 的统一功能和平台原生窗口控件 | 功能意图对齐；原生控件视觉存在平台边界 |

## 本轮实施与验收

- 以 v0.10.8 tag 为基线新建发布分支，选取性适配功能；当前原始 v0.9.7 用户工作树保持原样。
- 新增项目文稿搜索及原生菜单/快捷键入口；搜索范围限 Markdown/文本扩展名，键盘支持结果导航及当前标签、新标签、新窗口打开。
- 阅读和编辑代码围栏统一为卡片。编辑卡片采用 CodeMirror BlockWrapper，不改动 Markdown 结构；代码状态按围栏维护。
- 版本统一为 0.10.9，更新双语发布说明。
- TypeScript/Vite 构建、ESLint、Prettier、前端测试已通过：47 个测试文件、423 项；Rust 23 项测试、fmt、Clippy、npm 依赖审计、Cargo 审计和 bundle 预算通过。
- Quick Look 扩展构建和测试通过；候选 `.app` 已生成。首次打包因缺少 updater 私钥而退出，使用禁用 updater artifacts 的本机调试配置重新成功打包。
- 当前 CUA 环境无法绑定本机 TextMark 窗口，所以本轮没有候选原生截图；上游 0.0.62 窗口可读。代码卡片和搜索交互有组件测试覆盖；候选原生窗口细节仍需标记未实测。

## 剩余验收项

- v0.10.9 已于 2026-09-25 正式发布，GitHub Actions 的质量门及全部 macOS、Windows、Linux 架构构建和安装/预览 smoke 检查均通过；发布包含 36 项安装包、签名、更新元数据、SBOM、说明和校验资产。
- 仍未完成本机候选应用的截图复审：当前 Mac 锁屏，CUA 无法连接窗口。需要解锁后检查宽/窄窗、工具栏、搜索调色板、阅读/编辑代码卡片、滚轮和 Mermaid 虚线箭头；代码与自动化测试不能代替这项视觉验证。

## v0.10.10 后续复核

- 将 TextMark 搜索与上游 `FileSearchMatcher` 的匹配字段规则逐项对照后，发现此前查询会将父目录中的字符误当成文件名匹配；但结果仅在文件名里高亮，匹配依据和显示不一致。
- 已修正：普通查询只匹配文件名；查询包含 `/` 时才匹配相对路径，并在相对路径中高亮匹配字符。
- 新增目录名误匹配和相对路径模糊匹配回归用例；项目搜索测试 4 项通过，全套前端测试 47 个测试文件、425 项通过，ESLint、Prettier 与生产构建通过。
- 上游参考：[v0.0.62 FileSearchMatcher](https://github.com/pluk-inc/markdown-preview/blob/main/md-preview/Features/FileSearch/FileSearchMatcher.swift)、[搜索结果行](https://github.com/pluk-inc/markdown-preview/blob/main/md-preview/Features/FileSearch/FileSearchPanelController.swift)。

## v0.10.11 后续复核

- 再次对照上游 `FileSearchMatcher` 的结果排序与 `FileSearchPanelController` 的初始布局，发现 TextMark 使用贪心子序列匹配，且空查询时提前显示结果列表和页脚，与上游的动态规划命中及紧凑面板状态不一致。
- 已新增动态规划 fuzzy subsequence 匹配器，偏好连续片段、词边界和驼峰边界，并回溯实际匹配字符供高亮使用；搜索调色板无查询时收起结果列表，输入后再展开。
- 新增匹配算法与紧凑初始状态组件回归用例；全量前端测试 48 个文件、429 项通过；ESLint、Prettier 格式检查、生产构建通过。
- 尚未进行候选原生窗口截图比对：本机 Mac 仍锁屏，CUA 无法连接；应用布局与交互的实机视觉验收仍需解锁后完成。源码对照不等同于桌面视觉完全一致。

## v0.10.12 后续复核

- 再次检查搜索桌面布局和键盘操作：TextMark 原搜索为全屏暗色遮罩、620px 面板、16px 输入；上游使用 480px 浮动面板、20px 查询框、约 40px 结果行，初始只显示搜索框。TextMark 原先也缺少 Home、End、PageUp、PageDown 导航。
- 已调整搜索面板到 480px、20px 输入和 20px 圆角，并去掉全屏暗化；在窗口上方约四分之一处展示，最多显示六行结果。保留 TextMark 的关闭按钮、快捷键提示和跨平台能力。
- 项目索引排序移至 Web Worker，先计算匹配分数并选取前 30 条，再为可见项计算高亮位置；增加短防抖、陈旧请求丢弃和新查询期间 Enter 等待行为。补齐方向键、Home、End、PageUp、PageDown 导航。
- Playwright 用临时预览页检查了 1440×900、980×700 布局、空查询收起、18 个匹配结果、Home/End 选择、输入后立即回车打开和控制台无错误；临时预览页已移除。它验证 React/WebView 视图，不是候选 `.app` 的原生窗口实测。
- 前端测试 48 个文件、432 项通过；ESLint、Prettier 和生产构建通过。实际 macOS 窗口仍因系统锁屏无法截图，原生标题栏、窗口定位、玻璃材质与阅读/编辑视图尚未完成实机复核。
